# Данные

`python -m pregnancy_monitor generate` создаёт `synthetic_hr.csv` и файл метаданных.
Эти данные — инженерная фикстура, а не измерения беременных и не физиологическая модель.

Все CSV, результаты, локальные веса и секреты исключены из Git. Реальные измерения
нельзя добавлять в публичный репозиторий. Исключение из Git не заменяет управление
доступом и защиту данных на компьютере или сервере.

Контракт: `series_id,timestamp,heart_rate_bpm`. `series_id` — псевдоним, время — ISO 8601
с часовым поясом, пульс — число в уд/мин. Дополнительных столбцов пока нет.
Пример: `synthetic_001,2026-01-01T00:00:00Z,75.0`.
