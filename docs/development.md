# Следующие этапы проекта

## Текущее состояние

Есть числовой прогноз пульса на час без дообучения, воспроизводимые сравнения
и приватный API. Это исследовательский прототип. Модель не определяет состояние
плода, диагноз и риск осложнений. Реальные измерения проекта пока отсутствуют.

| Этап | Что сделать | Проверяемый результат |
|---|---|---|
| 1. Датчик | Подтвердить точную модель VivaLNK, SDK, лицензии, Android/iOS, доступные показатели, единицы и частоты | Паспорт источника и пример обезличенного экспорта |
| 2. Качество данных | Определить источник `quality`, обработку обрывов BLE, движения, дублей и потери контакта | Размеченные хорошие и плохие записи, проверяемое решение о допустимости прогноза |
| 3. Выборка | Установить правила сбора и доступа, выделить участниц и периоды для независимой проверки | Версионированный набор данных и заранее зафиксированные разбиения |
| 4. Оценка | Сравнить Chronos‑2 с простыми методами, проверить ошибку по горизонтам, покрытие, отказы, задержку и память | Отчёт на реальных данных с заранее согласованными техническими критериями |
| 5. Приложение | Клиент Flutter: история, график прогноза и его интервала, давность показаний, состояния отказа; основной сервер с пользовательской авторизацией | Тестовый сценарий Android/iOS → основной сервер → закрытый прогнозный API |
| 6. Интерпретация | Подключить отдельную модель объяснения после согласования формулировок с врачом | Проверяемые объяснения без подмены измерений и врачебных решений |

Сравнение со сдвигом уровня или шумом на синтетике не заменяет этапы 2–4.
Пока используется готовая Chronos‑2 без изменения весов. Дообучение имеет смысл
рассматривать только после появления данных и устойчиво измеренной ошибки
на независимой проверке. Локальная адаптация и настройка порогов также потребуют
отдельной проверочной части, чтобы не подбирать решение по окончательному тесту.

Медицинский специалист команды должен определить допустимые заявления продукта,
сценарии использования и план клинической проверки. Наличие консультанта или
модели прогноза само по себе не подтверждает клинические свойства продукта.
